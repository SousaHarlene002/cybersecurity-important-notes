# IP Addresses

## Introduction

An Internet Protocol (IP) address is a numerical identifier assigned to a device or network interface that uses the Internet Protocol for communication.

IP addresses allow devices to identify and communicate with each other across networks.

Examples of devices that can use IP addresses include:

* Computers
* Smartphones
* Servers
* Routers
* Printers
* Internet of Things (IoT) devices

---

## IPv4

IPv4 is one of the most widely used versions of the Internet Protocol.

An IPv4 address consists of four numerical sections separated by periods.

Example:

```text
192.168.1.10
```

Each section can contain a value from **0 to 255**.

---

## Private and Public IP Addresses

IP addresses can generally be categorized as public or private.

### Private IP Address

Private IP addresses are used within local networks.

Common private IPv4 ranges include:

```text
10.0.0.0 – 10.255.255.255
172.16.0.0 – 172.31.255.255
192.168.0.0 – 192.168.255.255
```

For example:

```text
192.168.1.10
```

may identify a device inside a home network.

### Public IP Address

A public IP address identifies a network or device on the public Internet.

A home router, for example, may have a public IP address assigned by an Internet Service Provider (ISP).

---

## IPv6

IPv6 is a newer version of the Internet Protocol designed to provide a much larger address space than IPv4.

An IPv6 address may look like:

```text
2001:db8:85a3::8a2e:370:7334
```

IPv6 uses hexadecimal notation and supports a vastly larger number of addresses.

---

## IP Addresses and Cybersecurity

Understanding IP addresses is important in cybersecurity because network traffic is often associated with source and destination IP addresses.

Security professionals may use IP addresses when:

* Investigating network activity
* Configuring firewalls
* Monitoring connections
* Identifying suspicious traffic
* Restricting access
* Troubleshooting network problems

However, an IP address alone does not necessarily identify a specific person.

---

## Static and Dynamic IP Addresses

### Static IP

A static IP address remains the same unless it is manually changed or reconfigured.

Static addresses are often useful for servers and network devices that need predictable addressing.

### Dynamic IP

A dynamic IP address can change over time.

Devices on local networks commonly receive dynamic IP addresses through **DHCP (Dynamic Host Configuration Protocol)**.

---

## Conclusion

IP addresses are fundamental to network communication.

Understanding the difference between IPv4 and IPv6, public and private addresses, and static and dynamic addressing provides an important foundation for learning network security.
