# Multi-Factor Authentication (MFA)

## Introduction

Multi-Factor Authentication (MFA) is a security method that requires users to provide more than one type of authentication factor when accessing an account or system.

MFA provides an additional layer of protection beyond a password.

If an attacker obtains a user's password, a second authentication factor may still prevent unauthorized access.

---

## The Three Main Authentication Factors

Authentication factors are commonly divided into three categories.

### 1. Something You Know

This is information that the user knows.

Examples include:

* Passwords
* PINs
* Security questions

### 2. Something You Have

This is something the user possesses.

Examples include:

* A mobile phone
* A security key
* An authentication device
* A smart card

### 3. Something You Are

This refers to a biometric characteristic.

Examples include:

* Fingerprints
* Facial recognition
* Iris recognition

---

## How MFA Works

A simplified example:

```text
Username + Password
        ↓
Second Authentication Factor
        ↓
      Access
```

For example, a user may enter their password and then confirm the login using an authentication application or security key.

---

## Common MFA Methods

### Authentication Applications

Applications can generate temporary verification codes or approve login requests.

### Security Keys

Physical security keys can be used to authenticate users to supported services.

### SMS Codes

Some services send a temporary code through SMS.

Although SMS can provide additional protection compared with a password alone, it has security limitations and is generally not considered as strong as some other modern authentication methods.

### Biometrics

Some systems use fingerprints or facial recognition as an authentication factor.

---

## MFA and Password Security

MFA does not replace the need for strong passwords.

Instead, it adds another layer of protection.

For example:

```text
Strong Password
      +
     MFA
      =
Stronger Account Protection
```

---

## Advantages of MFA

MFA can help protect accounts against:

* Stolen passwords
* Password reuse
* Credential stuffing
* Some phishing attacks
* Unauthorized login attempts

However, MFA is not completely immune to attack. Some social engineering attacks can attempt to trick users into approving fraudulent authentication requests or revealing temporary codes.

---

## Best Practices

* Enable MFA on important accounts.
* Prefer stronger authentication methods when available.
* Never approve an unexpected login request.
* Never share authentication codes.
* Keep recovery methods secure.
* Use security keys when appropriate.
* Be cautious of unexpected MFA notifications.

---

## Conclusion

Multi-Factor Authentication provides an additional layer of security by requiring more than one authentication factor.

Using MFA together with strong, unique passwords can significantly reduce the risk of unauthorized account access.

MFA is especially important for protecting sensitive accounts such as email, financial, educational, and professional accounts.
