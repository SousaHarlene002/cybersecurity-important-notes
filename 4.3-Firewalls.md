# Firewalls

## Introduction

A firewall is a security system designed to monitor and control network traffic according to predefined rules.

Firewalls can help prevent unauthorized network connections while allowing legitimate traffic to pass.

They are commonly used on computers, servers, routers, and organizational networks.

---

## How Does a Firewall Work?

A firewall examines network traffic and compares it against security rules.

A simplified example:

```text
Incoming Traffic
       ↓
    Firewall
       ↓
   Security Rules
     ↙     ↘
  Allow    Block
```

The specific rules depend on the firewall configuration.

---

## What Can a Firewall Control?

Depending on the firewall and its configuration, rules may consider information such as:

* Source IP address
* Destination IP address
* Source port
* Destination port
* Protocol
* Network interface
* Connection state

---

## Types of Firewalls

### Network Firewall

A network firewall controls traffic between networks.

For example, a firewall on a router can help control traffic between an internal network and the Internet.

### Host-Based Firewall

A host-based firewall runs directly on an individual device.

It can control network connections to and from that device.

### Hardware Firewall

A hardware firewall is a dedicated network device that provides firewall functionality.

### Software Firewall

A software firewall runs as an application or system component on a computer or server.

---

## Firewall Rules

A firewall can contain rules that determine which traffic is allowed or blocked.

For example:

```text
Allow HTTPS traffic
Block unauthorized incoming connections
Allow trusted network traffic
Block specific unwanted traffic
```

Firewall rules should be carefully configured and regularly reviewed.

---

## Firewalls and the Principle of Least Privilege

A useful security principle is **least privilege**.

This means providing only the access that is necessary.

For network security, this can mean limiting unnecessary ports and services rather than allowing unrestricted traffic.

---

## Limitations of Firewalls

Firewalls are an important security control, but they cannot protect against every type of attack.

For example, a firewall may not prevent:

* Phishing
* Social engineering
* Stolen credentials
* Malware introduced through an authorized connection
* Attacks against an application that is intentionally exposed to the Internet

This is why firewalls should be part of a broader security strategy.

---

## Conclusion

Firewalls help protect networks and systems by controlling network traffic according to security rules.

Proper configuration, regular review, and combination with other security controls are important for effective network protection.
