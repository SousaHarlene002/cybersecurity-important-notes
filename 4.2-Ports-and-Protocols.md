# Ports and Protocols

## Introduction

Network communication depends on protocols and ports to organize how devices and applications communicate.

Understanding ports and protocols is important in cybersecurity because they can help security professionals identify and control network services.

---

## What is a Network Protocol?

A network protocol is a set of rules that defines how devices communicate and exchange information.

Different protocols are designed for different purposes.

Examples include:

* HTTP
* HTTPS
* DNS
* SSH
* FTP
* TCP
* UDP

---

## What is a Network Port?

A network port is a logical communication endpoint used by applications and services.

Ports are identified by numbers ranging from **0 to 65535**.

A simplified example is:

```text
IP Address + Port
192.168.1.10:443
```

The IP address identifies the network destination, while the port helps identify the service or application endpoint.

---

## Common Ports

Some commonly encountered ports include:

| Port | Protocol/Service | Common Purpose         |
| ---: | ---------------- | ---------------------- |
|   22 | SSH              | Secure remote access   |
|   25 | SMTP             | Email transmission     |
|   53 | DNS              | Domain name resolution |
|   80 | HTTP             | Web traffic            |
|  443 | HTTPS            | Secure web traffic     |
|  110 | POP3             | Email retrieval        |
|  143 | IMAP             | Email retrieval        |
| 3389 | RDP              | Remote desktop         |

These are common associations, but the presence of a port number does not guarantee that a particular service is actually running there.

---

## TCP

Transmission Control Protocol (TCP) is a connection-oriented protocol.

It provides mechanisms that help ensure data is delivered reliably and in the correct order.

TCP is commonly used by applications that require reliable communication.

---

## UDP

User Datagram Protocol (UDP) is a connectionless transport protocol.

UDP generally has less communication overhead than TCP but does not provide the same built-in reliability mechanisms.

It is commonly used in applications where speed or low latency is important.

---

## HTTP and HTTPS

### HTTP

HTTP is a protocol commonly used for communication between web browsers and web servers.

### HTTPS

HTTPS is HTTP transmitted over a secure encrypted connection using TLS.

HTTPS helps protect data exchanged between a browser and a website from unauthorized observation or modification during transmission.

However, HTTPS does not automatically mean that a website itself is trustworthy.

---

## DNS

The Domain Name System (DNS) translates domain names into IP addresses.

For example:

```text
example.com
     ↓
   DNS
     ↓
IP address
```

This allows users to access websites using domain names instead of remembering numerical IP addresses.

---

## SSH

Secure Shell (SSH) is a protocol commonly used for secure remote administration of computers and servers.

It can provide encrypted communication between the client and the remote system.

---

## Ports and Cybersecurity

Security professionals monitor ports because exposed services can increase the attack surface of a system.

Unnecessary services should generally be disabled or restricted.

Firewalls can also be configured to control which network connections are allowed.

---

## Conclusion

Protocols define how network communication works, while ports provide logical endpoints for network services.

Understanding protocols and ports is essential for learning about firewalls, network scanning, network attacks, and other areas of network security.
