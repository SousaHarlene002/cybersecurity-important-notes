# Password Attacks

## Introduction

Password attacks are attempts to obtain, guess, or compromise passwords in order to gain unauthorized access to accounts or systems.

Attackers can use different techniques depending on the information they have and the security controls protecting the target.

Understanding common password attacks helps users and security professionals understand how to defend against them.

---

## Brute-Force Attack

A brute-force attack attempts to guess a password by trying many possible combinations.

For example, an attacker may systematically try different combinations of characters until the correct password is found.

Short and simple passwords are generally more vulnerable to brute-force guessing than long and complex secrets.

---

## Dictionary Attack

A dictionary attack uses a list of words and commonly used passwords to attempt to guess a password.

Instead of trying every possible combination, the attacker focuses on combinations that are more likely to be used by people.

For example, a dictionary may contain:

```text
password
welcome
admin
football
letmein
```

Using common words or predictable passwords can therefore increase the risk of a successful dictionary attack.

---

## Credential Stuffing

Credential stuffing occurs when attackers use previously exposed username and password combinations to attempt to access other services.

This attack relies heavily on **password reuse**.

For example:

```text
Website A → username + password exposed
                 ↓
          attacker tries
                 ↓
Website B → same username + password
```

If the victim reused the same password on both websites, the attacker may gain access to the second account.

Using unique passwords for different services is an important defense against credential stuffing.

---

## Password Spraying

Password spraying is an attack in which an attacker tries a small number of commonly used passwords against many different accounts.

Instead of trying many passwords against one account, the attacker may try one common password against many accounts.

This can sometimes help attackers avoid account lockout mechanisms designed to detect repeated login attempts against a single account.

---

## Phishing and Password Theft

Passwords can also be stolen through social engineering.

For example, an attacker may create a fake login page and convince a victim to enter their credentials.

This is why password security is closely connected to social engineering and phishing.

---

## Keyloggers

A keylogger is a type of malicious software or hardware that can record keystrokes.

If a device is compromised by a keylogger, passwords typed by the user may potentially be captured.

Protecting devices against malware and keeping software updated can help reduce this risk.

---

## How to Protect Against Password Attacks

Some important security measures include:

* Use long and unique passwords.
* Avoid common passwords.
* Never reuse passwords across important accounts.
* Use multi-factor authentication.
* Use a password manager.
* Keep software and operating systems updated.
* Be careful with suspicious links and login pages.
* Monitor accounts for unusual activity.
* Change compromised passwords immediately.

---

## Conclusion

Password attacks can use guessing, previously exposed credentials, malware, or social engineering to compromise accounts.

Strong unique passwords, multi-factor authentication, password managers, and security awareness can significantly reduce the risk of successful password attacks.
